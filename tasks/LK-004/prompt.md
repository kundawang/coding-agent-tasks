我有个打格斗的朋友，老抱怨"我明明按对了，游戏就是不认"。我想给他做个网页版的连招练习器，
让他能看清楚到底是自己按晚了还是窗口太窄。

招式帧数据和要练的连招我都整理在 samples 里了（moves.json / combos.json），格式 README 里有，
这两个文件别改。

想要的：

屏幕上显示一个按键输入条，把玩家的输入按帧画出来（哪个键、第几帧），下面接一条时间轴显示招式的
startup / active / recovery 三段。做完一套连招就标出每一步成没成、差了几帧。

关键是指令识别要经得起看：

- 有的招式是单键（5L），有的是要摇杆（236L、623H），摇杆输入要在一个几帧的窗口里完成才算，
  窗口宽度得能配，而且要在界面上显示出来。
- 要有输入缓冲：人在 recovery 里就按了下一招，命中后能接上，不能因为早按两帧就吞掉。
- 连招成立与否要看 hitstun 和 cancelInto：不在 hitstun 里、或者这招不能取消成下一招，就得算断连，
  而且要说清楚是"按晚了"还是"这招接不上"。

我最想要的是**慢放复盘**：一套连招打完，能拖回去一帧一帧看，看到底是第几帧按的、判定窗口是第几帧到第几帧。
所以按键记录必须逐帧存下来，能导出成一段记录给别人复现（他录一段发我，我这边能放出一模一样的）。

还要统计：每套连招的成功率、平均多/少几帧、最好的那次。我要拿这个看他练一周有没有进步。

硬约束：不要第三方库、不要 npm、不要构建步骤，原生 ES module；用 Canvas 还是 DOM 你看着办。
帧率固定按 60 算，别做成跟真实时间绑定的。
