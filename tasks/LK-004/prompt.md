我有个打格斗的朋友，天天抱怨"我明明按对了它就是不认"。我想给他做个网页版的连招练习器，
让他自己看清楚到底是手慢了还是窗口太窄。

招式的帧数据、要练的连招，都在 samples 里（moves.json、combos.json），README 有格式说明，这俩别改。

界面上我想要一串按键输入条，按帧画出来，哪个键第几帧按的都看得见；下面接一条时间轴，
把招式的 startup/active/recovery 三段画出来。一套连招打完，每一步成没成一目了然，还得告诉我差了几帧。

指令识别这块最容易被喷，你自己掂量：单键的（5L）还好，摇杆的（236L、623H）得在一个几帧的窗口里输完才算，
窗口多宽我想能配，而且界面上得画出来，不然我说不清。还有输入缓冲——人在 recovery 里就按了下一招，
命中之后应该能接上，不能因为早按两帧就把输入吃了。连招成不成立得看 hitstun 和 cancelInto：
不在僵直里、或者这招压根不能取消成下一招，就得判断，而且要说清楚是"按晚了"还是"这招接不上"。

我最想要的是能慢放。一套打完能拖回去一帧一帧看：我第几帧按的、判定窗口是第几帧到第几帧。
所以按键得逐帧存，能导出给别人复现——他录一段发我，我这边能放出一模一样的。

再帮我统计下：每套连招成功率多少、平均早/晚几帧、最好那次是几次。我要拿这个看他练一周有没有长进。

别引库别 npm 别构建，原生 ES module，Canvas 还是 DOM 你看着办。帧率就按 60 算，别跟真实时间绑。
README 写清楚怎么开、判定窗口最后定的多少帧、记录格式长啥样。
