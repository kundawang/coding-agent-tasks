做了个俯视角的小赛车原型，想让同事午休的时候在浏览器里比圈速，谁快谁请奶茶。赛道和车的数据我量好了放仓库里（data/tracks.json、data/cars.json），物理和界面你来写。

纯静态，原生 ES module，不引构建、不装依赖。车辆物理、边界判定、检查点、回放这些纯逻辑拆出来，用 node --test 测。

要点：

- 车在俯视图里跑，操作就三个：油门、刹车、左右转向。物理用固定步长积分（cars.json 里 tick_rate=60），加速度、最大速度、转向速度、抓地力都按数据来，别写死。松油门自然减速（有阻力），刹车更快。
- 抓地力决定"侧滑"：转向时如果横向速度太大，车会滑出去（drift_grip 比 grip 低），我要的就是这个手感——转急了会飘，不是贴在地上转。
- 赛道由中心线一串点 + 宽度定义（tracks.json），渲染用 canvas 把路面画出来（中心线两侧各半宽）。车出路面就按 off_track_penalty 降速，撞到外边界按 wall_bounce 弹一下，不能穿出去。
- 记圈：必须按顺序过 checkpoints 才算一圈（跳点不算），过 start 线完成一圈。显示当前圈速、上一圈、最佳圈、总圈数（tracks.json 里 laps）。
- 最佳圈要留"影子车"：把那一圈的输入（每个 tick 的油门/转向）存下来，之后每圈都拿它回放对比。samples/ghost.json 是输入日志的格式样例（每 4 个 tick 记一条），照它来。

界面：canvas 画赛道和车，HUD 显示速度、圈速、最佳圈、圈数；下面一条简易的速度/油门条。开跑前能选赛道和车。
