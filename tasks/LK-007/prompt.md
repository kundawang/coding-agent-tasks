我和我弟想在一台电脑上对战，两个人挤一个键盘那种。玩法是抢点：地图上三个据点，站上去几秒占下来，
占着就持续加分，三分钟谁分高谁赢。

地图和规则参数在 samples 里（arena.json / rules.json），格式 README 里有，别改。

想要的：

玩家一 WASD、玩家二方向键，移动、抢点、加分、结算，两个人都要有复活和出生无敌（防着一出生就被堵）。
手感上要"撞得住"——人不能穿墙，也不能互相穿过。

这题我最在意的是**逻辑要固定 tick 跑**。因为两个人在同一个屏幕上，如果逻辑跟着渲染帧率走，
一个人 165Hz 一个人 60Hz 打出来的判定就不一样了。所以逻辑按 rules.json 里的 tickRate 固定步长推进，
渲染只是把最新状态画出来，掉帧不能改变实际发生的事。

第二条是**回放**。一整局要能导出成记录，别人贴回来能一帧一帧重放出刚才那局——谁在哪一 tick 按了什么、
哪一 tick 占点、分怎么涨的，都要对得上。我打算拿这个复盘"你明明早到了怎么还是我的分"。
记录格式你自己定，写进 README。既然要回放，那局的推进就不能依赖真实时间或者 Math.random 的隐式状态，
随机的东西（比如出生点朝向）也得能从种子重放出来。

顺便要个观战模式：两边都打完可以慢放看刚才那局，能拖时间轴。

硬约束：不要第三方库、不要 npm、不要构建步骤，原生 ES module + Canvas，我 `python -m http.server` 开。
