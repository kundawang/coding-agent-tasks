我们在做一个网页版的回合制炮击对战小游戏（内部代号 shardwake）：两个人在同一台电脑上轮流操作，调角度和力度把对方炸掉，地形会被炸坏。地形和武器数据在仓库里（data/terrain.json、data/weapons.json、samples/replay_demo.json），物理和界面你来写。

技术上：纯静态，原生 ES module，不引构建工具、不装依赖，起个静态服务就能玩。核心逻辑（地形插值、弹道积分、爆炸挖地、伤害衰减、坠落伤害）拆成单独模块，用 node --test 写测试。

一、地形

按 data/terrain.json 的控制点用余弦插值算出每个 x 像素的地面高度（越小的 y 越高），地形是一整块可以被打掉的实体，不是一条线：每个 x 有一个"从地面高度到画面底部"的实心列，爆炸会把这个范围挖出圆形缺口（缺口下方可以悬空）。渲染用 canvas，地形用一格一格的像素块画，挖掉的部分要能明显看出来。

二、回合与操作

两个玩家轮流，各自站在地形上。一个回合里：

1. 回合开始时按 seed 决定本回合的风（水平方向，范围 -60 ~ +60 px/s²），并且**先把风显示出来**，玩家看得到再打。
2. 可以左右移动，最多 60 像素（贴着地形走，走不过陡坡就停下）。
3. 可以调角度（0~90 度，以自己朝向的正前方为 0 度，P1 朝右、P2 朝左）和力度（0~100）。
4. 开火：弹丸按固定步长积分（dt = 1/120 秒），受重力和风影响，撞到地形或玩家就爆炸。

键盘操作（同屏双人）：P1 用 A/D 移动、W/S 调角度、Q/E 调力度、空格开火；P2 用方向键移动/调角度、逗号句号调力度、回车开火。鼠标拖拽调角度力度也要能用。

三、武器与伤害

武器见 data/weapons.json。爆炸时：

- 先把圆形范围内的地形挖掉（半径就是 radius）；
- 对范围内的玩家按距离线性衰减：中心满伤，边缘 50%，向下取整；
- 集束弹爆炸后在原地再撒 3 颗子弹（位置由 seed 决定，必须在界面上看得出来）；
- 钻地弹先钻进地形再爆炸（挖的洞更深），具体表现你自己定，写进 README。

地形被挖空后玩家会往下落，落差超过 30 像素时受到 `floor((落差 - 30) / 2)` 点坠落伤害。玩家血量 100，降到 0 以下判负，另一方获胜。

四、可回放

所有随机（风、集束弹的散布、其他任何随机）都必须来自 seed 驱动的自研 PRNG，写清楚用的哪个算法。每个操作都记一条日志（移动了多少、角度、力度、武器、是否开火），给一个"回放"按钮，拿 seed + 日志重放，重放结束时双方血量、位置、地形缺口、剩余弹药都要和原来一样。samples/replay_demo.json 是一份操作样例。

五、界面

canvas 里画地形、两个玩家、血条；顶部显示当前轮到谁、当前武器和剩余弹药、本回合的风速风向（带箭头）；瞄的时候显示角度/力度读数和一条很短的出膛方向指示。上一发的弹道轨迹留一条淡淡的残影，方便下一次修正——这条对我们手感很重要，别省。
打完显示胜负，能给"同种子再来一局"和"换种子重开"。
