想做个网页版的回合制炮击对战，两个人挤一台电脑轮流打，地形会被炸坏——就是小时候那种调角度调力度互相轰的玩法，我要的就是那个手感。地形和武器数据在 data/terrain.json、data/weapons.json。

地形：terrain.json 里给了 12 个控制点，相邻两点之间用余弦插值，算出每个 x 像素处的地面高度。注意地形是实心的，从地面往下全是土，不是一条线——爆炸要把那块挖成圆洞，洞底下能悬空，人站的地方被挖了要往下掉。canvas 画，土一格一格画，挖掉的地方要看得出来。

一回合这么走：开始先按 seed 摇一个风（水平方向的加速度，-60 到 +60），**先把风向风力显示出来**再让我瞄，不然纯靠猜没法玩；然后我能左右挪最多 60 像素（贴着地形走，太陡上不去），调角度 0-90 度（以自己面朝的方向为 0 度，1P 朝右、2P 朝左），调力度 0-100，最后开火。弹丸用固定步长积分（dt=1/120 秒），受重力和风，撞到地形或人就炸。

伤害：爆炸先把半径内的地形挖掉，再对范围内的玩家按距离衰减——中心满伤、边缘减半，向下取整。武器见 weapons.json，集束弹炸完原地再撒 3 颗子弹（位置由 seed 定，要看得见），钻地弹先钻进去再炸，具体怎么表现你定，写 README 里就行。地形被挖空后掉下去的，落差超过 30 像素吃坠落伤害，(落差-30)/2 向下取整。血量 100，归零就输。

操作要同屏双人：1P 用 A/D 走、W/S 调角度、Q/E 调力度、空格开火；2P 用方向键和逗号句号加回车。鼠标拖着调角度力度也得能用，不然试手感太慢。

回放这块必须有：风、集束弹散布、任何随机都走 seed（PRNG 自己写一个，README 里写清是哪个算法）。每回合的操作记一条，点回放拿 seed + 日志重放，最后双方血量、位置、地形缺口、剩余弹药都要一致。samples 里给了操作日志样例。

界面：canvas 画地形、人、血条；顶上写轮到谁、当前武器和弹药、本回合风向（带箭头）；瞄的时候显示角度力度读数和一小段出膛方向。**上一发的弹道留一条浅色残影**——这条对我调手感特别重要，别省。打完给个"同样子再来"。美术没有，canvas + CSS 就行。
