# emberdeck

我们自己玩的卡牌构筑，网页版原型。单机，一个人打 AI。

纯静态、无构建、无依赖，起个静态服务就能开。

## 目录

```
samples/cards.json      卡表（18 张）
samples/encounter.json  这一场的双方配置：血量、能量、牌组
```

## 规则（我们平时玩的简化版）

### 一回合

1. 回合开始：能量回满（默认 3），抽 5 张牌。
2. 出牌：每张牌标了费用，能量不够就打不出去。目标要合法（写着打敌人的牌不能指自己）。
3. 结束回合：手上剩下的牌全部进弃牌堆，然后轮到对面；对面的回合跑完再回到你。
4. 抽牌堆抽空了就把弃牌堆洗回去接着抽（用同一个随机源）；两边都不够抽就少抽点，别报错。
5. 手牌上限 10 张，超过的直接进弃牌堆。

### 状态

| 名字 | 效果 | 什么时候掉 |
|---|---|---|
| 力量 `strength` | 每层让你打出的攻击牌基础伤害 +1 | 不掉，整局累积 |
| 易伤 `vulnerable` | 受到的攻击伤害 ×1.5 | 每过一回合减 1，减到 0 就没了 |
| 虚弱 `weak` | 打出的攻击伤害 ×0.75 | 同上 |
| 护甲 `block` | 先扣护甲再扣血 | 自己回合开始时清零 |

### 伤害怎么算

按这个顺序算，最后一步向下取整：

```
单次命中伤害 = floor( (牌面伤害 + 力量) × 易伤(1.5) × 虚弱(0.75) )
```

多段攻击（比如「造成 2 次 4 点伤害」）每段**单独算、单独扣护甲**，不是先加起来再算一次。
战斗中的伤害数字随时可以在界面上看到，我怎么算的你得能在界面上对得上。

### 卡表格式

```json
{
  "id": "strike",
  "name": "突刺",
  "cost": 1,
  "target": "enemy",
  "exhaust": false,
  "effects": [{ "kind": "damage", "amount": 6 }],
  "text": "造成 6 点伤害。"
}
```

| 字段 | 说明 |
|---|---|
| `target` | `enemy` / `none` / `self` |
| `exhaust` | true 表示打出后进消耗堆，不进弃牌堆 |
| `effects` | 从上往下依次结算 |

`effects` 里我们用到的几种：

| kind | 参数 | 说明 |
|---|---|---|
| `damage` | `amount`，可选 `times` | 造成伤害，`times` 默认 1，多段就写几 |
| `block` | `amount` | 获得护甲 |
| `draw` | `amount` | 抽牌 |
| `energy` | `amount` | 获得能量 |
| `apply` | `who`（enemy/self）、`status`、`amount` | 上状态，`amount` 是层数（易伤/虚弱就是回合数） |
| `heal` | `amount` | 回血，不超过上限 |
| `loseHp` | `amount` | 掉血，无视护甲 |

### AI 那副牌怎么打

`samples/encounter.json` 里给了它一副牌。它每回合就做一件事：手上有能打的牌就打，
优先打带 `damage` 的，能量不够就停，目标永远是你。不需要更聪明的策略。
