# Neon Commute · 年会打歌赛

纯静态网页音游：四条轨道、D/F/J/K 按键、WebAudio 现场合成 8-bit 伴奏。
无第三方库、无构建步骤、无后端，起一个静态服务就能玩。

## 怎么开

```bash
# 任选其一，在本目录下执行
python -m http.server 8000
node serve.mjs 8000        # 没装 Python 时的零依赖备用方案
```

浏览器打开 `http://localhost:8000`。必须走 http（不能直接双击 html 文件），
因为谱面是 `fetch('samples/chart.json')` 加载的。

## 玩法

- 音符落到判定线时按对应轨道的 `D` `F` `J` `K`。
- `Esc` 暂停/继续。暂停时音频时钟冻结，音符停在原地，回来不错位。
- 打完出成绩页，填名字存本地排行榜（localStorage，按分数排序）。
- 排行榜可导出 JSON 发群里，别人粘贴回来点「导入合并」即可并榜（按 id 去重）。

## 判定窗口（最终定值）

| 档位 | 窗口（\|偏差\|） | 得分 | 准确率权重 |
|---|---|---|---|
| Perfect | ≤ 30ms | 1000 | 1.0 |
| Great | ≤ 60ms | 600 | 0.7 |
| Good | ≤ 100ms | 300 | 0.4 |
| Miss | > 100ms / 漏击 | 0 | 0 |

- 准确率 = 权重和 ÷ 总音符数 × 100%。
- 空敲（窗口内没有音符）不惩罚；漏击自动判 Miss 并清空连击。
- 想调窗口就改 `js/judge.js` 顶部的 `WINDOWS`，一处生效。

## 时间轴设计（为什么掉帧不影响判定）

- 全局唯一时钟是 `AudioContext.currentTime`。伴奏按谱面 `bpm`/`offsetMs`
  用 lookahead 调度器排进音频时钟；音符位置、判定时刻、校准全部换算成
  "歌曲毫秒"后对齐这条时钟。
- 渲染循环（rAF）只负责"画"，每帧从音频时钟取当前位置，掉帧只是少画几帧，
  不会让音符漂移，更不会影响判定结果。高刷屏（165Hz）同理。
- 暂停用 `AudioContext.suspend()` 直接冻结时钟本身，恢复时从冻结点继续，
  暂停时长天然不计入歌曲时间。
- 判定与分辨率无关（纯时间计算），窗口缩放、全屏切换只影响画面布局，
  每帧按当前画布尺寸重算几何。

## 键盘延迟校准

- 菜单进「校准键盘延迟」：2 拍低音预备 + 4 拍高音计测，跟着最后 4 声敲任意键。
- 算法：每拍在 ±250ms 内匹配最近的一次敲击，得到 4 个偏差样本，
  取**中位数**作为本机输入延迟（至少匹配 3 拍才生效，防误触）。
- 结果存入 localStorage，之后每局判定自动从按键时刻中扣除该偏移；
  排行榜每条成绩都记录当时是否校准及偏移值，校准前后的成绩一眼可分。
- 换机器/换键盘后重新校准一次即可。

## 目录结构

```
index.html          页面骨架（菜单/校准/结算/排行榜四个界面）
style.css           样式
js/main.js          界面流程串联
js/game.js          游戏主循环：Canvas 渲染 + 键盘判定
js/audio.js         WebAudio 8-bit 合成器 + 音频时钟
js/judge.js         判定窗口/计分（纯计算）
js/calibrate.js     校准算法（纯计算）
js/leaderboard.js   榜单排序/合并/序列化（纯计算）+ localStorage 存取
samples/chart.json  谱面（128bpm，offset 120ms，804 音符，勿改）
test/logic.test.mjs 纯逻辑测试
serve.mjs           零依赖静态服务器（备用）
```

## 测试
