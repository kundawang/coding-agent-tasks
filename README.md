# seedforge

用种子生成地牢地图的小工具，网页版。同一个种子永远生成同一张地图，地图可以编码进链接发给别人。

纯静态、无构建、无依赖。

## 目录

```
samples/presets.json   几套生成参数
samples/seeds.txt      一串平时用的种子
```

## 生成参数

```json
{
  "id": "cramped",
  "name": "窄道",
  "width": 64, "height": 48,
  "roomMin": 5, "roomMax": 11,
  "roomCount": 18,
  "corridorWidth": 1,
  "extraLoops": 2,
  "treasureRooms": 3
}
```

| 字段 | 说明 |
|---|---|
| `width` / `height` | 网格尺寸（格） |
| `roomMin` / `roomMax` | 房间边长范围 |
| `roomCount` | 目标房间数（放不下就少放几个，但不能报错） |
| `corridorWidth` | 走廊宽度 |
| `extraLoops` | 除了生成树之外额外连几条环路 |
| `treasureRooms` | 标注几个宝箱房 |

## 种子

`samples/seeds.txt` 里一行一个种子，允许是任意字符串（数字、单词、一串乱码都行），
同一个种子必须生成完全一样的地图。

## 运行

纯静态、无依赖、无构建。任意静态服务器指向本目录即可，例如：

```
python -m http.server 8000
```

然后打开 `http://localhost:8000`。左侧改参数、点「重新生成」即时重绘；
「复制链接」得到带参数的短链接，「导出 PNG」存图，「复制坐标」把房间/出生点/宝箱房坐标以 JSON 复制到剪贴板。

## 随机源设计

`js/rng.js`：字符串种子先过 xmur3 风格的哈希混成 32 位整数，再驱动 mulberry32
产生随机流。全程只用 `Math.imul` 和无符号位移，不碰 `Date`、不碰语言自带的随机函数，
所以任何引擎、任何机器上逐位一致。生成器（`js/dungeon.js`）只在固定顺序的
`for` 循环里消耗随机流，不依赖对象键序或 Set/Map 迭代顺序——测试里专门有一项
把参数对象的键倒序重建后再生成，断言网格逐格相同。

## 链接编码

`js/codec.js`：8 个数值参数用 `.` 连接，加上种子和一个校验值，形如
`64.48.5.11.18.1.2.3~lantern~i9km4u`，整体 base64url 编码后放进 `#m=...`。
整条链接一般 50~70 个字符。校验值是 `hashSeed("参数~种子")` 的 36 进制表示，
截断、改字符、换种子都会被识别。解码函数永不抛异常：字符集、长度、字段个数、
数值范围、参数自洽性（roomMax ≥ roomMin、宝箱房 ≤ 房间数）、校验值逐项检查，
任何一项不过就返回错误信息，页面显示提示并退回默认地图，不会白屏。

## 连通性保证

1. 房间随机放置，带 1 格间距，互不重叠；尝试次数有上限，放不下就少放，
   一个都放不下时在地图中央兜底放一间，绝不死循环、绝不产出空图。
2. 走廊沿房间完全图的 Prim 最小生成树开凿，所以所有房间必然连通；
   再按 `extraLoops` 从剩余边里加环路。
3. 开凿只把墙改成地板，从不把地板填回墙，不会挖穿房间或画出重叠的墙。
4. 宝箱房取从出生房 BFS 步行距离最远的若干间，保证出生点到每个宝箱房有路。

## 验证

```
node test/run-tests.mjs
```

覆盖：四套预设 × 全部样例种子的逐格确定性（含键序无关）、全房间/全宝箱房/
全地板格 BFS 可达、极端参数（120 个房间塞 16×16 之类）下的退化与连通、
链接往返一致、十余种篡改链接全部被拒、生成链路源码中无语言自带随机函数。
