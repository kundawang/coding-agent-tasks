# neon-commute

年会午休打歌赛用的网页版音游。纯静态、无构建、无后端，起个静态服务就能开。

## 目录

```
samples/chart.json   扒好的一首谱面（3 分钟，804 个音符）
```

## 谱面格式

```json
{
  "title": "Neon Commute",
  "bpm": 128,
  "offsetMs": 120,
  "lanes": 4,
  "bars": 96,
  "notes": [{ "t": 120, "lane": 0 }]
}
```

| 字段 | 说明 |
|---|---|
| `bpm` | 曲速。伴奏按它合成 |
| `offsetMs` | 第一拍相对曲子 0 点的位置，伴奏从这个位置起拍 |
| `lanes` | 轨道数，固定 4 |
| `notes` | 音符表，`t` 是毫秒（从曲子 0 点开始算），`lane` 是轨道号 0~3 |

`notes` 按 `t` 升序；同一个 `t` 上出现两条表示双押。
